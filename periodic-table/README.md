# Periodic Table
Version: 1.3.0

An interactive reference table of all 118 elements, with color modes for metal, nonmetal and metalloid, for the s, p, d and f blocks, and heatmaps of atomic radius, electronegativity and first ionization energy with trend arrows.

## Assumptions and departures
- This is a reference page, not a practice activity, so it does not use the shared activity engine (`shared/zsa-engine.js`, `shared/zsa-activity.css`). It loads `shared/zsa-base.css` and `shared/zsa-embed.js` and follows the same house rules: a strict IIFE per script, no globals, the shared CSP, no inline scripts or styles, no storage, cookies, analytics or outside requests at run time.
- `data.js` is generated by `tools/build-data.js` (Node, no dependencies) from a JSON snapshot of the mendeleev package in `tools/sources/`. Edit the build script and rerun `node periodic-table/tools/build-data.js` from the repository root; do not edit `data.js` by hand. `tools/extract-mendeleev.py` (Python standard library) refreshes the snapshot from the package's database. The `tools/` folder is published with the site but is not loaded by the page.
- Every word on the page that changes with the data (mode names, legend text, trend sentences, details labels) is in `data.js`, written by the build script.
- The top of the page shows the ZornScience logo (linking to https://zornscience.org/), the title "Periodic Table" and the Full screen button. A "← Back to the lesson" link appears next to the title only when a lesson link passes `?from=`. Embed mode (`?embed=1`) hides the logo, the back link and the footer; the page title stays visible.
- Built and browser-tested in Chromium by Claude. Real screen readers, Firefox, Safari and school devices remain untested. See TESTING.md.

## Purpose
A reference students can open from any lesson or activity that shows a table, and a way to see periodic trends as heatmaps. Lessons that link here:
- Chemistry Unit 2: Periodic Trends (Groups), Periodic Trends (Periods)
- Chemistry Unit 1: Metals, Nonmetals & Metalloids
- AP Chemistry 1.7 Periodic Trends
- Every activity that shows a periodic table

## What it shows
- The full 18-column table with the lanthanide and actinide rows below. Group 3 in periods 6 and 7 holds a "57-71" and "89-103" placeholder.
- Each cell: atomic number, symbol, and in block and heatmap modes the block letter or the value.
- Color modes: Block (s, p, d, f; the default when the page opens), Category (metal, nonmetal, metalloid), Atomic radius, Electronegativity, Ionization energy. Heatmaps use seven steps of the site's blues, light to navy, with a legend that gives each step's range and units. Elements with no value are gray with a dashed border and show "n/a".
- Color is never the only cue: heatmap cells show their value, block cells show their block letter, metalloid cells have a dashed border, and every cell's accessible name includes the category, block or value with units.
- Trend arrows (heatmap modes, on by default): an arrow across the top ("Across a period: increases" or "decreases") and one down the left side ("Down a group"), plus one sentence each in the lessons' words (effective nuclear charge across a period, more energy levels down a group). Ionization energy adds one line about the small dips from group 2 to 13 and from group 15 to 16.
- Details panel (tap, click or Enter on an element): atomic number, symbol, atomic mass, group, period, block, type, state at room temperature, full and noble-gas electron configurations, valence electrons (main groups), common ion charges with names, electronegativity, atomic radius and first ionization energy, plus notes for configuration exceptions, predicted values and borderline classifications.
- Search by name, symbol or atomic number (British spellings aluminium, caesium and sulphur also work). The match is highlighted and receives focus; Enter then opens its details.
- **Share** (top right): opens a panel with the link to this view and Copy link, Email, Facebook and X, plus "More share options" (the device share sheet) where the browser has one. The link is `https://activities.zornscience.org/periodic-table/` with the current `mode`, any open element (`el`) and `trends=0` if the arrows are off; it never includes `from` or `embed`. Facebook and X are ordinary links the student chooses to follow (they open in a new tab); nothing is loaded from them on this page. Escape, the × button or a click outside closes the panel. Hidden in embed mode and in full screen. On phones the Share and Full screen buttons show only their icons.
- A "Data sources" note at the bottom of the page.
- **Full screen** (for presenting on a projector or interactive whiteboard): the "Full screen" button at the top right (solid blue, with four arrows pointing outward) makes the whole page fill the screen, like presenting in Google Slides. The logo, back link, footer and data sources are hidden, and the element cells grow to fill the height left under the toolbar, so the whole table still fits even if the toolbar wraps (a larger font or browser zoom): about 81 by 90 px per cell at 1920x1080, and the table fits at 1366x768, 1280x720 and 4:3 projectors such as 1024x768. Every color mode, the trend arrows, search, the keyboard grid and the details panel keep working. Esc or "Exit full screen" returns to the normal page; in full screen, the first Esc leaves full screen and a second one closes the details. The button only appears where the browser allows full screen: it is hidden on iPhones (Safari has no full screen for web pages there) and in a frame that does not allow it.

Radius type: every radius on the page is the single-bond covalent radius of Pyykkö and Atsumi (2009), in picometers. It is the one consistent set that covers all 118 elements, noble gases included. Covalent radii of the noble gases come from calculations, and a few values do not follow the simple trend (for example fluorine 64 pm is larger than oxygen 63 pm, and neon 67 pm is larger than fluorine). The page shows the data as it is.

## Decisions for the teacher to confirm
Each is one line in `tools/build-data.js`.
- **Metalloids**: exactly the lesson's six, B, Si, Ge, As, Sb, Te.
- **Borderline cases** (shown with a note in their details):
  - Polonium is shown as a metal. Some tables call it a metalloid.
  - Astatine is shown as a nonmetal, with the other halogens. Some tables call it a metalloid or a metal.
  - Selenium is a nonmetal here; some tables call it a metalloid.
  - Hydrogen sits in group 1 and is a nonmetal.
  - Elements 112 to 118 (Cn, Nh, Fl, Mc, Lv, Ts, Og) are classified by their place in the table (Ts and Og as nonmetals, the rest as metals). Only a few atoms of each have been made, so their notes say the classification is predicted.
- **Group 3 and the f-block rows**: the rows below the table hold La to Lu and Ac to Lr (15 each), all shown as f-block with no group number. IUPAC has discussed putting Lu and Lr (instead of La and Ac) in group 3; the second source places La and Ac in group 3, which is the only reason the group check skips these 30 elements.
- **Atomic masses**: 2 decimal places (fewer when the standard value has fewer, so lead is 207.2). Brackets hold the mass number of the longest-lived isotope for elements with no standard atomic weight: Tc, Pm, Po to Ac, and Np to Og. Thorium, protactinium and uranium have no stable isotope but do have IUPAC standard atomic weights, so they are shown as 232.04, 231.04 and 238.03, like most school tables. Bismuth (209Bi decays extremely slowly) is shown as 208.98.
- **Francium's state** is shown as solid with a note. Its melting point is only estimated (mendeleev 294 K, which would make it a liquid at 25 °C; pymatgen 300 K, a solid). The other liquids are bromine and mercury.
- **Common ions**: main groups follow the lessons' rule (groups 1, 2 and 13 lose 1, 2 and 3 electrons; nonmetals and metalloids in groups 15, 16 and 17 gain 3, 2 and 1). So arsenic is 3− and antimony is 3− (antimonide), although antimony also forms 3+ and 5+ compounds. Boron, carbon, silicon and germanium show "No common simple ion" with a note. Hydrogen shows 1+ and 1−. Tin and lead 2+ and 4+, thallium 1+ and 3+, bismuth 3+, polonium 2+ and 4+. Transition metal charges are the common ones taught in high school, entered by hand: Sc 3+; Ti 4+, 3+; V 5+, 3+; Cr 3+, 2+; Mn 2+, 4+; Fe 2+, 3+; Co 2+, 3+; Ni 2+; Cu 2+, 1+; Zn 2+; Y 3+; Zr 4+; Nb 5+; Mo 6+, 4+; Tc 7+, 4+; Ru 3+, 4+; Rh 3+; Pd 2+, 4+; Ag 1+; Cd 2+; Hf 4+; Ta 5+; W 6+, 4+; Re 7+, 4+; Os 4+; Ir 3+, 4+; Pt 2+, 4+; Au 3+, 1+; Hg 2+, 1+ (mercury(I) is Hg2 with 2+). Lanthanides and actinides 3+, except Ce 3+, 4+; Eu 3+, 2+; Th 4+; Pa 5+; U 6+, 4+; Np 5+; Pu 4+; No 2+, 3+. Elements 104 to 118: none listed.
- **Valence electrons** are given for main-group elements only (helium 2). d- and f-block elements say "Not counted this way for d- and f-block elements".
- **Electron configurations** are written in filling order, [Ar] 4s2 3d10 4p5, matching how students fill orbitals. The 22 real exceptions are flagged in the details with the filling-order prediction: Cr, Cu, Nb, Mo, Ru, Rh, Pd, Ag, Pt, Au, La, Ce, Gd, Ac, Th, Pa, U, Np, Cm, Lr, and the predicted Ds and Rg.
- **Missing values** are gray, not guessed: electronegativity for He, Ne, Ar, Kr, Rn, Pm, Eu, Tb, Yb, Am to Lr and 104 to 118; ionization energy for 109 to 118.

## Where the second source disagrees
All 118 elements were compared with the second source (TESTING.md). Symbols, names, periods, groups (outside the f-block rows), standard atomic masses and atomic radii agree. Every disagreement:
- **Bracketed mass numbers for superheavy elements** (the sources pick different longest-lived isotopes): Rf [267] vs [261], Db [268] vs [262], Sg [271] vs [266], Bh [274] vs [264], Hs [269] vs [277], Mt [276] vs [268], Rg [281] vs [272], Mc [288] vs [289]; Og [294] has no value in the second source.
- **Electron configurations**: none for the elements the second source covers. It has no configuration for Db to Og, so those 14 predicted configurations are checked only for electron count.
- **Electronegativity**, beyond 0.05: Tc 2.1 vs 1.9, Lu 1.0 vs 1.27, W 1.7 vs 2.36, Pt 2.2 vs 2.28, Au 2.4 vs 2.54, Hg 1.9 vs 2.0, Tl 1.8 vs 1.62, Pb 1.8 vs 2.33, Bi 1.9 vs 2.02, U 1.7 vs 1.38, Np 1.3 vs 1.36. The second source mixes in values for higher oxidation states (Pb 2.33 is Pb(IV)); the page keeps the CRC values. Values the second source has and the page leaves gray: Kr 3.0, Rn 2.2, Pm 1.13, Eu 1.2, Tb 1.1, Yb 1.1, and 1.3 for Am to Lr (estimates). None of these affect the Periodic Trends Practice, which uses periods 2 to 5 without noble gases for electronegativity.
- **First ionization energy**, beyond 5 kJ/mol: none. The second source gives theoretical values for Mt (4824 kJ/mol) and Ds (6272 kJ/mol) that are far from any expected value; the page leaves them gray.

## Keyboard and screen readers
- The table is an ARIA grid with one Tab stop. Arrow keys move between elements and skip the gaps: Up from boron goes to helium, Up from scandium to magnesium, Down from yttrium or radium into the lanthanide row, Up from the f-block rows back into the main table. Home and End move to the first and last element in the row; Ctrl+Home and Ctrl+End go to hydrogen and oganesson.
- Enter or Space opens the details panel and moves focus to its heading. Escape (from the table or the panel) or "Close details" closes it and returns focus to the element.
- Each cell is read as name, symbol and atomic number, then the category, the block, or the heatmap value with units ("Fluorine, F, atomic number 9, Electronegativity 3.98"; "Neon, Ne, atomic number 10, Electronegativity: no data"). The selected element has aria-selected. The trend arrows are hidden from screen readers because the sentences under the legend say the same thing.
- The color modes are a radio group; the trend arrows are a checkbox; search has a visible label and a polite status line.
- Nothing moves focus on first load, including deep links.

## Layout
- 1340 px and wider (laptops at 1366x657): the whole table, including both f-block rows, is on screen at once with the details panel on the right. The legend runs along the empty part of period 1 and the trend sentences sit above the transition metals.
- 1280 to 1339 px: the same, with the legend below the table.
- 900 to 1279 px: the table fits the width (cells at least 44 px wide); the details panel is below.
- Narrower than 900 px: the page never scrolls sideways. The table scrolls sideways inside a labeled region with a "Scroll sideways for more →" cue. Search, keyboard moves and deep links scroll the region (never the page) to the element. The legend, trend sentences and details panel are below the region, so they work without scrolling the table.
- Every button, link, control and element cell is at least 44 by 44 px.

## Links and URL parameters
Views are linkable with URL parameters only (nothing is stored):
- `mode`: `block` (default), `category`, `radius`, `electronegativity`, `ionization`
- `el`: a symbol or atomic number; opens that element's details without moving focus, for example `?mode=electronegativity&el=F`
- `trends=0`: trend arrows off
- `from`: adds a "← Back to the lesson" link to that page, for `https://zornscience.org/` pages only (https, that exact host, no port or user name). Without it, or with anything else, there is no back link; the logo always links to https://zornscience.org/.
- `embed=1`: embed mode. To offer the Full screen button in an embed, the iframe needs the `allowfullscreen` attribute.

Changing the mode, the arrows or the open element updates the address with `history.replaceState`, so a teacher can copy the link. Other parameters, such as `from`, are kept.

Live URL after merging: https://activities.zornscience.org/periodic-table/
Example lesson link: `https://activities.zornscience.org/periodic-table/?mode=radius&from=https://zornscience.org/science/chemistry/unit-2-quantum/periodic-trends-periods/`

## Installation and local use
Keep these folders at the repository root: `shared/` (zsa-base.css, zsa-embed.js, fonts/) and `periodic-table/`. From the repository root, run `npm run serve` (or `python3 -m http.server 8000`) and open `http://localhost:8000/periodic-table/`. The page needs no build step to run.

## Known limitations
- No pronunciation, discovery history, isotopes or photos. Values are the ones listed above; other references may round differently.
- Covalent radii are one of several radius definitions; textbooks that use metallic or atomic radii show different numbers (especially for metals and noble gases).
- Current Chrome, Edge, Firefox and Safari iOS 16+ are intended targets, but only Chromium was tested. The mode buttons use the CSS `:has()` selector for their checked style; older browsers still show the native radio button.
