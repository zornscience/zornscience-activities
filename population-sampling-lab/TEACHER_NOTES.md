# Population Sampling Lab teacher notes

Version: 1.0.0

This is an illustrative teaching model, not real data. All tables below were generated by running model.js. The model is deterministic, stateless, and available through module.exports in Node and an event handshake in the browser.

## Pure model API

`const m = require("./population-sampling-lab/model.js");`

| Function | Result |
| --- | --- |
| `seed(value)` | Unsigned 32-bit integer for finite numeric input, otherwise null. |
| `random(seed, stream=0, index=0)` | New independent deterministic generator returning values from zero inclusive to one exclusive. |
| `meadow(seed)` | `{total, clusters, counts, plants}`. Plants have x, y in meters and cell index 0 to 99. |
| `pond(seed)` | Fixed true fish population for the visit. |
| `randomQuadrat(seed, usedCellIndices, index=0)` | Uniform unused cell, or null if all 100 have been used. Does not mutate used cells. |
| `quadratEstimate(counts)` | Mean count times 100, or null for no counts. |
| `estimate(M, C, R)` | Rounded mark and recapture estimate, or null for R zero. |
| `percentError(guess, truth)` | Absolute whole percent error, or null for an undefined guess. |
| `capture(seed, {M=20, C=20, trial=0, condition="off", stream=0})` | `{M,C,R,first,marked,second,estimate,condition,trial}`. Fish IDs are zero-based. Choices are 20, 30 or 40. Conditions are off, wear, avoid. |

Pass normalized seeds to model operations. The browser takes one cryptographic seed only if the query has no valid seed. Streams 1, 2 and 3 isolate meadow, pond and quadrat locations. Capture uses streams 10+stream, 30+stream and 50+stream for the first catch, mark survival and second catch. Trial indices start at zero within each series. Investigation 2 uses stream 0; Investigation 3 uses stream 100. Off and on comparisons share first catches and random numbers, while mark survival or weights change the result.

## Default guided choices

The interface begins with I choose. For reproducible keys, choose A1 through A10, then B1 through B10 in order. This is a documented teacher path, not an automatic student selection. For Random, call randomQuadrat with all previously used cells and index equal to their count. Both paths reveal at 3, 10 and 20 samples. Enter the rounded model estimate at each reveal. Students may enter a different estimate, so compute its error with percentError.

Run five trials (indices 0 to 4) with 20/20 and five with 40/40 in their separate series. Problems use 30/30, five trials each. Each series allows eight trials; reveals lock that series. The two off problem series have identical keys, since both use the same unbiased pond model and stream. A best estimate is a student choice, so it has no single answer key.

## Interpretation

Random placement removes deliberate preference for dense habitat. A single random estimate can still miss a clump. More quadrats reduce typical sampling error across many samples, but the 20-quadrat estimate need not be closer in every visit. Let students use their actual percent errors.

The simple mark and recapture estimator is nonlinear and can have large outliers or be undefined. Do not substitute zero when R is zero. Larger catches usually reduce central spread and make zero recaptures less common. A raw finite-estimate range is a poor aggregate comparison: the largest possible finite 20/20 estimate is 400, while 40/40 can reach 1600. The statistical test uses the interquartile range of finite estimates relative to each pond and separately counts undefined trials. Five classroom dots may show a different ordering. Do not promise improvement for every seed or series.

Lost marks and avoidance lower typical R and raise estimates across many fixed seeds. Individual pairs can tie or reverse because samples vary. Baseline trials can already overestimate due to the simple reciprocal estimator. Discuss closed population, lasting marks, mixing and equal catch probability. The pond intentionally holds population size fixed to isolate sampling effects.

## Worksheet prompts

1A. Compare your 3-quadrat estimate to your 20-quadrat estimate. Which was closer to the true total? Use your percent errors as evidence.

1B. Compare your "I choose" estimate to your Random estimate. Explain why choosing the quadrats yourself can give a biased estimate.

1C. Why do scientists sample instead of counting every organism?

2A. Describe how your five estimates with M = 20, C = 20 compare to your five with M = 40, C = 40. Use the spread of the dots as evidence.

2B. Explain, in your own words, why the number of marked fish in the second catch (R) tells you about the whole pond.

2C. What would you change to get a more reliable estimate?

3A. How did your estimates change when marks wore off? Explain why.

3B. How did your estimates change when marked fish avoided the net? Explain why.

3C. Name one assumption of mark and recapture and explain what happens if it is false.

## Knowledge check key

1. Every quadrat has a fair chance of being sampled.
2. Larger or repeated samples reduce the influence of an unusual sample.
3. R is smaller than expected when the estimate is too high.
