    Rearranging equations

    • Solve for the variable with letters first. Substitute the numbers last.
    • An equation is a balance: do the same step to both sides, using the opposite operation.
    • Undo steps in reverse order: F = 1.8C + 32 becomes C = (F − 32)/1.8.
    • A variable in the denominator: multiply both sides by it, then divide. D = m/V gives DV = m, so V = m/D.
    • The triangle shortcut works only for three-letter formulas like A = BC, and only to check your work.

    Rearranged formulas: t = d/v, a = F/m, m = DV, V = m/D, c = q/(mΔT), m = q/(cΔT), a = (vf − vi)/t, t = (xf − xi)/v.
