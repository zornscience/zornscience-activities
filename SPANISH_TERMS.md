## Agreement notes

- Element names take the article el in running sentences (el sodio, del cloro), but not in headings, answer choices or chips. Periodic Trends passes the article inside each template slot ({theLabel}, {aHigher}) so English stays unchanged.
- VSEPR geometry names are feminine (lineal, trigonal plana, tetraédrica, piramidal trigonal, angular) so they agree with geometría and distribución in every Lewis builder sentence. The Lewis builder is a Chemistry activity, so it uses estructura de Lewis, not the AP term diagrama de Lewis.
- Stoichiometry Coach and Limiting Reactant Visualizer use relación molar, the Chemistry page term, not the AP term razón molar.
- Where a count would force agreement with a noun that changes, the Spanish template puts the count after a label (Reacciones: 2 de 4, Resueltos en esta sesión: 3), so one template is correct for every number.

## Deliberately incorrect naming choices

Metal-name distractors are intentionally invalid names ending in `uro`: litiouro, sodiouro, potasiouro, rubidiouro, cesiouro, magnesiouro, calciouro, estronciouro, bariouro, aluminiouro. Negative-ion distractors deliberately keep `ion de` plus the element name instead of the correct anion name. These are wrong answer choices, never glossary recommendations.

Chemical formulas, symbols, numerical charges, state markers, units, keyboard key names and proper source titles retain their original notation. `picometers`, `kilojoules`, `mol` and `electron volts` remain unit names; prose uses `por mol`.
