# Polyatomic Ion Trainer

Version: 2.0.2

Flashcards and individual four-choice quiz practice for the exact 17 shaded ions on the Common Polyatomic Ions classroom chart. Excludes all seven unshaded ions from cards, questions, answer choices, and reference. Includes alternate names and acetate notation. No introduction band; uses the shared ZornScience logo, Inter font, and navy/blue styles.

Options start collapsed and expand by tap or keyboard. On phones, settings stack vertically with 48px controls.

Choose both directions, formula + charge → name, or name → complete formula + charge. Study all ions, either negative charge group, ammonium/phosphate, or the chlorine family.

Flashcards require recall before flipping, then self-rating. Practice-again cards return after up to three intervening cards. A session ends when all queued cards are marked recalled. End session shows progress at any time. Ratings include repeated cards.

Quiz covers each selected ion once, gives feedback after each response, prevents duplicate scoring, and ends with accuracy, points and best streak. Untimed is default. Optional 20-second questions use a wall-clock deadline; timed-out questions count as incorrect and feedback remains until Next. Correct answers earn 100 points independent of speed. Review missed ions starts a new session using just the missed set. Quiz choices draw from the 17 shaded ions so even two-ion sets have four distinct answers.

Reference lists all 17 shaded ions with aliases and highlights useful family patterns. Students are encouraged to retrieve before revealing and revisit on another day. State stays in the tab; no accounts or stored student data. This is individual practice, without multiplayer rooms or leaderboards.

Keyboard: Tab/Enter/Space operate flashcards and controls; keys 1-4 select quiz answers. Corrections use text and symbols as well as color. Responsive phone layout preserves 44px targets. Share uses the current page address and excludes results.
