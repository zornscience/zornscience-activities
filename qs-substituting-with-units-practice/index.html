    Substituting with units

    • Substitute each value with its unit. Units multiply, divide and cancel like letters: (12 m/s)(4.0 s) = 48 m.
    • Named units: N = kg·m/s² and J = N·m = kg·m²/s².
    • Convert to kg, m and s before you substitute: 425 g × (1 kg / 1000 g) = 0.425 kg, and 85 cm × (1 m / 100 cm) = 0.85 m.
    • Predict the answer's unit, then check it: t = d/v gives s, so it is right; t = v/d gives 1/s, so the setup is wrong.
    • Gas laws use kelvin: K = °C + 273, with R = 0.0821 L·atm/(mol·K).

    Formulas: D = m/V, d = vt, v = d/t, F = ma, W = Fd, KE = ½mv2, P = nRT/V.
