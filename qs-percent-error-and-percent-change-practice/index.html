    Percent error and percent change

    • Percent error = |measured − accepted| ÷ accepted × 100.
    • The accepted value is the true value scientists agree on. It always goes on the bottom.
    • The absolute value bars make percent error positive. It is never negative.
    • Percent change = (new − original) ÷ original × 100. The original value always goes on the bottom.
    • Keep the sign: positive means an increase (+35%), negative means a decrease (−25.0%). Always subtract new minus original.
