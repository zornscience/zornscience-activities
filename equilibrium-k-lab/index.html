Equilibrium Constant Lab

Instructions

Choose a reaction, predict its direction, and use equilibrium data to explain your answer.

  1. Set initial concentrations and run the reaction.
  2. Compare Q with K before revealing the shift.
  3. Build an equilibrium table one row at a time. Request hints when needed.
  4. Combine reactions or compare solubilities. Copy or download the data table.
