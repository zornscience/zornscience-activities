    Significant figure rules

    • Nonzero digits always count.
    • Zeros between nonzero digits always count: 4007 m has 4.
    • Leading zeros never count: 0.0052 g has 2.
    • Zeros at the end count only when there is a decimal point: 2.50 g has 3, but 2500 g has 2.
    • In scientific notation, count only the digits of the first number: 2.500 × 103 g has 4.
    • Rounding: if the first digit you drop is 5 or more, round the last kept digit up.
    • Multiplying or dividing: keep the fewest significant figures.
    • Adding or subtracting: keep the fewest decimal places.
