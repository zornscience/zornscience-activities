How completion codes work

Assign an activity

In Google Classroom, make an assignment and add the activity's link:

  • Predicting Ion Charge Trainer: https://activities.zornscience.org/ion-charge-trainer/
  • Ionic Formula Builder: https://activities.zornscience.org/ionic-formula-builder/
  • Periodic Trends Practice: https://activities.zornscience.org/periodic-trends/
  • Lewis Structure and VSEPR Builder: https://activities.zornscience.org/lewis-vsepr/. For the AP setting, add ?set=ap to the end of the link.
  • Gas Laws and KMT Lab (Investigations tab): https://activities.zornscience.org/gas-lab/

Ask students to finish one full round and paste their code into the assignment as a private comment or a short answer.

What students do

Students open the link and play a full round. No login is needed. At the end of the round, the summary shows a completion code and a Copy code button. Practicing one item (an element, compound, question, structure or investigation), a round of one trend, and Practice my misses do not give a code.

Check the codes

Paste one code or many into the box above and choose Check codes. Each row shows the activity, the day the round was finished (Central time, from the student's device clock), the number of items, the first-try correct count for each step, and how many times the student used Show me and Hint. Show me uses of 63 or more, or hints of 127 or more, show as "63 or more" and "127 or more".

  • Valid: the code reads correctly. For the Lewis Structure and VSEPR Builder, the activity name ends with the setting the round was played with: "(Octet rule)" or "(AP setting)".
  • Typo or edited: a character is wrong, missing or swapped, or the code was changed by hand. Ask the student to copy it again.
  • Unknown activity: the code is well formed but comes from an activity this checker does not know. Reload this page to get the newest version.
  • Future date: the code is dated after today, usually because the device's clock is wrong.
  • No code found: the line has no code on it.

What a code can and cannot prove

A code shows that a full round with these results was finished on that day. It does not show who finished it: codes have no names, so a student could pass a code to a friend, and two students with the same results on the same day get the same code. The date comes from the device clock, which a student can change. The check characters catch typos and casual editing, but someone who reads the activity's source code could make a code by hand. Use codes as a record of practice, not as a test score.
