# AP Chemistry Unit 8 Practice

Version: 1.0.2

Original bilingual ZornScience practice aligned to College Board CED Unit 8, Acids and Bases. Each of eleven topics has six questions: four multiple choice and two numeric entry. Total: 66 questions, 44 multiple choice and 22 numeric, with individual explanations for all 132 distractors in English and Mexican Spanish. These are original aligned questions, not official College Board exam items.

## Reference, precision and assumptions

The reference includes Kw, hydronium and hydroxide logarithms, the 25 °C pH/pOH relation, conjugate Ka × Kb, pKa, Henderson-Hasselbalch, percent ionization, ICE guidance, buffer reactions and a table of every Ka/Kb used. Chemical formulas and charges use real subscript and superscript markup. Equilibria use ⇌ and complete neutralizations use →. Explanations use hydronium.

pH, pOH, pKa and equilibrium constants use the existing `ratio` unit ID: no units / sin unidades. Concentrations and molar solubility use M; amounts use mol; titrant volume uses mL. Logarithmic answers use `precision: {decimals:n}` and explain that n equals significant figures in the controlling concentration or K value. The inverse-log question uses significant figures in the resulting ratio. Precision notes are advisory under the existing model. Tolerance follows the prior units' half-final-place convention with a 10% cushion.

Acetic acid is normally supplied with Ka = 1.8 × 10<sup>−5</sup>; one explicitly more precise measurement uses 1.80 × 10<sup>−5</sup>. Both appear in the reference. Weak acid and base calculations use full quadratics; the 5% check is taught separately. The calcium fluoride problem supplies the combined solubility equation. Both numeric solubility questions stipulate a large external pH reservoir and exclude complexes. A buffer depletion limit is labeled an upper stoichiometric limit, not useful capacity throughout that range.

## Interface and Spanish

Choose a six-question topic or Mixed review for all 66. Submit once, read feedback and continue. Results show topic scores and missed questions. Try again reshuffles questions and answer choices. Native controls support keyboard use; question and result headings receive focus and feedback is announced. Instructions and Share dialogs support Escape and return focus.
