## Independent worked answers

Worked before authoring the bank. These are original questions aligned to College Board CED topics 8.1 to 8.11, not official exam items. Solutions are ideal and dilute, with concentrations approximating activities. Temperature is 25 °C unless explicitly changed. Equilibrium constants are dimensionless. Strong acid-base neutralizations go to completion; weak acid-base processes use equilibrium. Keep unrounded intermediate results.

For pH, pOH and pKa, decimal places equal significant figures in the governing concentration or K value. When several measured inputs apply, the least precise input controls. Kw = 1.0 × 10<sup>−14</sup> and pH + pOH = 14.00 are the stipulated 25 °C reference values, not a reason to discard precision supplied by a strong-electrolyte concentration. Numeric precision feedback remains advisory under the existing engine.

## Reference and model checks

The Ka/Kb table lists every value used, including the explicitly hypothetical acid with Ka = 1.0e-3, acetic acid at both stated precisions (1.8e-5 and 1.80e-5), ammonia, HF and the derived acetate Kb. The calcium fluoride question supplies the combined-equilibrium solubility equation so students can calculate the effect of protonation. A sufficiently large external reservoir holds pH constant in both numeric solubility questions. No common ions or complexes are introduced.

The weak-acid titration curve is a schematic model, not measured data. Half-equivalence is 12.5 mL, equivalence is 25.0 mL. The species diagram is a model of normalized HA and A<sup>−</sup> fractions, not absolute concentrations. SVG titles, descriptions, labels and captions have Mexican Spanish translations, with the same facts repeated in prompts.

English and Spanish overview URLs were opened successfully through the web tool on November 7, 2026, with matching unit and topic titles. Direct curl access was blocked by the environment proxy, so URL validation used the web tool instead. No site content was modified.
