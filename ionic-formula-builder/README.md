# Ionic Formula Builder
Version: 1.0.1

## Assumptions and departures
- Claude will host these static files and the lesson link will be added on WordPress separately. This package makes no hosting or WordPress changes.
- Built from the Ion Charge Trainer 1.3.0 conventions: the same layout, tap-to-check choices, answer trail, hints, Show me, review and summary. Since 1.0.1 both activities run on the shared activity engine (`shared/zsa-engine.js` and `shared/zsa-activity.css`, see `shared/README.md`). `builder.js` keeps the formula and charge-sum helpers, the steps, the misconception rules, the compound strip and Practice my misses. Students see no change.
- File names are `builder.js` and `builder.css` (the trainer uses `trainer.js` and `trainer.css`). Each JS file uses its own strict IIFE, and the data and the engine reach the builder through one-use `zsa:request-data` and `zsa:request-engine` events.
- `data.js` is generated by `tools/build-data.js` (Node, no dependencies). The script criss-crosses the charges, reduces by the greatest common divisor, and writes the 80 compounds as an explicit table, one compound per line, together with the wrong name choices. Edit the script and rerun `node ionic-formula-builder/tools/build-data.js` from the repository root; do not edit `data.js` by hand. The `tools/` folder is published with the site but is not loaded by the page.
- Feedback, hints and explanations are templates in `data.js` filled from each compound's ions, instead of 80 hand-written copies. The fill-in slots are names, symbols, groups, charges, a formula and a charge sum.
- A round has 10 different compounds: 6 name to formula and 4 formula to name in random order. At least 3 have equal charges, at least 2 contain aluminum, and at least 2 need reducing (equal charges above 1, such as CaO or AlN) and are asked name to formula, so every round practices reducing. Review can add up to 3 items, with the Ion Charge Trainer's spacing rules. Review fillers get a random direction; the repeat keeps the direction that was missed.
- Practice my misses includes every missed compound in the direction it was missed, plus compounds with the same pair of charges, up to 10.
- First-try counts are kept separately for the four step types. Each count covers only the original compounds in that direction (6 and 4 in a mixed round). Hints do not reduce the count. Review and filler items do not affect it. Show me never counts as first-try correct.
- "Choose a compound" (under Practice options) has a second select for the direction. The compound list shows names, so a chosen formula-to-name item is for practice, not a test.
- Inter's alternate letters are turned on for this activity (`cv05`, a lowercase l with a tail, and `cv08`, a capital I with serifs). Without them, Al reads as AI and LiI as Lil.
- Embed mode hides the back link and eyebrow. Unlike the Ion Charge Trainer, the page title stays as a visually hidden h1 so the framed page still has a heading 1 (axe best practice).
- Version 1.0.0 was browser-tested in Chromium by Claude. Real screen readers, Firefox, Safari and school devices remain untested. See TESTING.md.

## Purpose and learning goal
Students go from a name to a formula and from a formula to a name for binary ionic compounds, using the lesson's method: binary ionic = metal + nonmetal; the metal keeps its name; nonmetal root + ide; no prefixes for ionic names; charges add to 0; criss-cross the charges; reduce to the lowest ratio; never write a subscript of 1; check: total charge = 0.

Lesson: https://zornscience.org/science/chemistry/unit-3-ionic-bonding/binary-compounds/

Name to formula (shown: aluminum oxide)
1. Ion charges, two parts: the metal ion's charge (1+, 2+, 3+) and the nonmetal ion's charge (1−, 2−, 3−).
2. How many of each ion, two parts: metal ions (1, 2, 3) and nonmetal ions (1, 2, 3). The formula builds as the counts are picked, with a live check line such as "2(+3) + 3(−2) = 0" or "(+2) + (−1) = +1, not 0".

Formula to name (shown: Mg<sub>3</sub>N<sub>2</sub>)
1. Which ions, two parts: the metal ion's charge and the nonmetal ion's charge. This catches reading subscripts as charges.
2. Name it: four choices, the correct name, a prefix name ("trimagnesium dinitride"), the element name without -ide ("magnesium nitrogen") and the reversed order ("nitride magnesium").

Each step gives targeted feedback, two hints (general, then specific), and Show me after two incorrect attempts.

Preserve these sibling folders at the repository root:

```

  index.html
  builder.css

  builder.js
  tools/build-data.js
  README.md
  TESTING.md
```

From the repository root, run `python3 -m http.server 8000` and open `http://localhost:8000/ionic-formula-builder/`. No build, dependencies or API keys are needed to run the page. Use the local server rather than opening the file directly, because browsers can treat the CSP `'self'` directive strictly for file URLs.

Standalone relative URL: `ionic-formula-builder/`
Embed relative URL: `ionic-formula-builder/?embed=1`
Live URL after merging: https://activities.zornscience.org/ionic-formula-builder/

Embed mode hides the back link, eyebrow and footer and sets remaining links to `_top`. When framed, the root reports a change in height with `{type: "zsa:resize", activity: "ionic-formula-builder", height: <integer>}` to `https://zornscience.org` only. No message is sent when the activity is the top-level window.

All answers stay in memory and reset on reload. Page loading requests only the local assets. There are no runtime data requests, cookies, storage, analytics, accounts or AI calls. Outbound navigation is limited to the lesson and license links.

## Misconception map and precedence
A correct answer is always checked first. Wording lives in `data.js` under `ui.feedback`.

| Step | Trigger | Targeted response |
|---|---|---|
| Charges (both directions) | Wrong metal charge | "Charges come from the group number." Then the metal's group and "How many electrons does it lose?" |
| Charges (both directions) | Wrong nonmetal charge | "Charges come from the group number." Then the nonmetal's group and "How many electrons does it gain to reach 8?" Both parts wrong: both messages, with the group rule once. |
| Which ions (formula to name) | A charge equal to that ion's own subscript, such as Mg 3+ for Mg<sub>3</sub>N<sub>2</sub> | "Subscripts count ions. Charges come from the group number." Takes precedence over the group message for that part. |
| Which ions (formula to name) | Same, when the subscript is an unwritten 1 (Ca 1+ for CaO) | Adds "A missing subscript means 1 ion, not a charge of 1." |
| Subscripts (name to formula) | Total charge is 0 but not the lowest ratio (Ca<sub>2</sub>O<sub>2</sub>, Ba<sub>3</sub>O<sub>3</sub>) | "2 : 2 is the same ratio as 1 : 1. Reduce to the lowest ratio." with the numbers picked. |
| Subscripts | One of each when the charges differ (MgCl) | The charge sum, for example "(+2) + (−1) = +1, not 0", then "One of each works only when the charges are equal." |
| Subscripts | Swapped, or each ion's own charge as its own subscript (Al<sub>3</sub>O<sub>2</sub>) | The charge sum, then "The charge of one ion becomes the subscript of the other ion." |
| Subscripts | Any other count that does not add to 0 | The charge sum, then "Criss-cross the charges so the total charge is 0." |
| Name it | Prefix name | "Never use mono-, di-, or tri- for ionic compounds. The charges already set the ratio." |
| Name it | Element name without -ide | "The nonmetal's name changes: nonmetal root + ide." |
| Name it | Reversed order | "Name the metal first. The metal keeps its name, then the nonmetal root + ide." |

There is no Check button. One-part steps check on tap; two-part steps check as soon as both parts are picked, in either order. A wrong pick is marked with an ✗, read as "(tried, not correct)", and cannot be picked again. In a two-part step only the wrong part is cleared; the right part stays picked, and the next pick in the cleared part checks again. In the subscripts step the tried formula and its charge sum stay on screen until the next pick. Every check counts as an attempt. Two incorrect attempts in a step show Show me and schedule a delayed review. Show me supplies the answer and explanation and moves on.

Hints: the first is general (the method), the second is specific to the compound. A hint in either charges step also highlights both group columns in the table.

## Layout
- One step at a time. A finished step becomes a chip in the answer trail (green check for correct, blue arrow for shown) and its explanation stays above the next step.
- The main-group periodic table is always visible with both elements of the compound marked, read as "(in this compound)". A charges hint highlights their group columns, read as "(hint)". After the charges step, each ion's charge appears above its group column (for example 3+ over group 13), read as "ion charge 3+". The charge line is always reserved, so the table never changes height.
- 900 px and wider: compound and table on the left, question on the right. Narrower: compound, table, then question, with a shorter header and denser table on phones. The two parts of a step sit side by side from 360 px.
- On screens narrower than 900 px, a new step scrolls so the compound strip is at the top when the step would otherwise run off the bottom. New feedback or a hint is scrolled into view if it lands below the screen. Neither happens in embed mode.
- Practice options (new round, choose a compound and direction) are in a collapsed panel under the activity.
- Measured fit (the step's buttons, feedback and the Next button on screen without the student scrolling, compound and table in view): 360x640, 390x664, 768x1024, 1280x617, 1366x657 and 1920x960. 320x568 needs a short scroll on step 2 and after feedback.

## Formulas and screen readers
- Formulas use real `<sub>` subscripts. One helper (`formulaToken` in builder.js) builds every formula: the visible formula is `aria-hidden` and a visually hidden version is read instead, such as "Al 2 O 3" or, in the answer trail, "Al 2 O 3, aluminum oxide". A formula-to-name compound is never read with its name before the name step is done.
- Charge sums use the same pattern: "2(+3) + 3(−2) = 0" is read as "2 times plus 3, plus 3 times minus 2, equals 0". The live region gets the spoken versions.
- Charges are written number first with the Unicode minus sign (U+2212): 2+, 3−.

## Keyboard controls
- Tab and Shift+Tab move between answer groups and buttons. Each answer group is one Tab stop.
- Arrow keys, Home and End move between the answers in a group without choosing one, so browsing never submits an answer.
- Enter or Space chooses the focused answer, which checks it (or, in a two-part step, checks once both parts are chosen). Enter or Space also activates other buttons.
- On first page load, focus stays at the top of the page. Each compound after that focuses its heading. A completed step focuses the next step's first choice. The last step focuses the "Compound complete" heading; the end of a round focuses "Round complete".
- After both hints are shown, the Hint button stays focusable but inactive (aria-disabled).
- Feedback uses a persistent polite live region. The table uses row and column headers.
- Practice options is a native disclosure: Tab to it and press Enter or Space to open it.

## Suggested shared changes
Done in 1.0.1: the choice groups (tap to check, tried marking, roving Tab stop, arrow keys), the main-group table and the rest of the shared behavior are now in the shared engine, and the root README lists current versions. Still suggested, not made, because they would change what one activity shows:
- A shared visually hidden class that can be applied by CSS (a mixin-style rule such as `.zsa-sr-only-css`), so activities do not repeat the clip rules for the phone table caption and the embedded h1.
- Embed mode in `zsa-embed.js` could keep the page h1 as a visually hidden heading instead of hiding it with the rest of the chrome, so framed pages keep a heading 1. This activity does it locally by marking only the top line as chrome.
- The `font-feature-settings: "cv05" 1, "cv08" 1` rule could move to `zsa-base.css`; the Ion Charge Trainer's table also shows Al and Cl.

## Known limitations
- No saving or grade reporting. This is formative practice.
- Binary compounds of the listed main-group ions only. No transition metals, Roman numerals, polyatomic ions or hydrates.
- The prefix-name wrong choices are deliberately covalent-style names that do not apply to ionic compounds.
- Current Chrome, Edge, Firefox and Safari iOS 16+ are intended targets, but only Chromium was tested.
