    Ratio and proportion rules

    • Write a ratio as 3 : 2, 3 to 2, or 3/2. The first quantity named goes first.
    • Simplify by dividing both numbers by the same factor: 12 : 8 = 3 : 2.
    • Change to the same units first: 50 cm : 2 m = 50 cm : 200 cm = 1 : 4.
    • In a balanced equation, the coefficients give the mole ratio: 2 H2 + O2 → 2 H2O (H2 : O2 = 2 : 1)
    • A proportion is two equal ratios. Keep the same units in the same spots and use x for the unknown: 120 km / 2 h = x km / 5 h
    • Cross-multiply, then divide: 2 · x = 120 · 5 = 600, x = 600 ÷ 2 = 300 km
