Physics Graphing Lab

Instructions

One moving cart. Three connected graphs. Make a prediction, run the experiment, and explain what changes.

  1. Set the cart conditions and predict its position, velocity, and acceleration graphs.
  2. Run the experiment and compare all three linked graphs.
  3. Pause or reset to compare trials and explain how the graphs describe the same motion.
