Test Policy Checker

Instructions

  1. Choose a state on the map, in the State list, or with the buttons under the map.
  2. Or type part of a school's name to search every state.
  3. Use Policy to show one kind of policy. The map then shows how many schools in each state have it.
  4. Each school shows its policy, the tests it accepts, any exception, and a link to the page we checked.
  5. On the map, use the arrow keys to move from state to state, and Enter or Space to choose one.
