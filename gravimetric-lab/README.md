Realistic illustrated bench simulation of U6.A2 gravimetric analysis. No data-entry fields, persistence, or network requests. Sodium and potassium unknowns alternate with New unknown. Uses the existing shared ZornScience branding and header controls. Heat, cool, precipitate, settle, filter, wash, and dry to constant mass. Model assumes quantitative recovery; residual moisture adds 0.032 g to the first precipitate weighing.
